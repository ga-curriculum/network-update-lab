## Outline the update

Now that you understand General's current network setup and goals, it's time to start outlining your vision for their network upgrade.

Based on your assessment findings and General's goals, list the key components of your recommended updates and improvements to the network.

For each component, provide a brief description of:

- What you're proposing.
- Why it's important (think about its benefits, like how it solves the current issues or supports future needs).

Don't worry about the technical details at this stage. Instead, focus on the big picture.

### What to include

Consider things like:

- Replacing or upgrading firewalls.
- Improving wireless access (for example, specific Wi-FI versions or technologies the new network will support).
- Supporting remote work securely (for example, VPN solutions or zero trust network architecture).
- Moving to cloud services.
- Simplifying network management.

Use any method you prefer - a bulleted list, a mind map, a flowchart - whatever helps you organize your thoughts.

### Keep it simple

At this stage, focus on the **what** and the **why**. We'll get into the **how** later on. The goal here is to paint a clear, compelling picture of your vision for General's network transformation.

Remember, a good plan is like a good network: structured, efficient, and able to handle whatever comes its way!
